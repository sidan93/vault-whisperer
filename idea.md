# EchoVault (или memex-tg) 🧠⚡

An elegant, zero-infra Telegram bot for instant thought capture and RAG-powered smart search over your local Obsidian Vault. Built with Python & ChromaDB.

Проект создан для удобного «быстрого захвата» заметок, мыслей и инсайтов на ходу через Telegram, автоматического превращения их в структурированный Obsidian-формат и последующего умного контекстного поиска по всей базе знаний.

---

## 🔥 Ключевые фичи

* **Instant Capture & Enrichment:** Отправь боту сырой поток мыслей или ссылку. LLM автоматически структурирует текст, выделит ключевые теги, добавит `frontmatter`-метаданные и сохранит как `.md` файл.
* **Smart RAG Search:** Вместо обычного полнотекстового поиска — семантический поиск по смыслу и синонимам. Бот понимает контекст вопроса, ищет релевантные чанки в локальной векторной базе и генерирует связный ответ на основе твоих же заметок.
* **Zero-Infra & Privacy:** Никаких тяжелых Docker-композиций или облачных векторных БД. Проект работает внутри одного Python-процесса, храня индекс локально на диске.
* **Obsidian-Native:** База знаний остается обычным набором Markdown-файлов. Синхронизация с локальным Obsidian на ПК настраивается через приватный Git-репозиторий.

## 🏗 Архитектура системы

    +-----------------------+
    |     Telegram Bot      |

    +-----------+-----------+-------------------+
    | (Запись)                                  | (Поиск)
    v                                           v
+--------+--------+                     +--------+--------+
|    LLM Agent    |                     |  Embedder API   |
| (Структуризация)|                     | (Векторизация)  |
    +                                           +
    |                                           |
    v                                           v
+--------+--------+                     +--------+--------+
|  Markdown File  |                     |  Chroma DB      |
| (Obsidian Vault)|+------------------->| (Локальный RAG) |
+-----------------+   (Индексация)      +--------+--------+
                                                |
                                                v
                                       +--------+--------+
                                       |    LLM Agent    |
                                       | (Синтез ответа) |
                                       +-----------------+

### Как это работает под капотом:
1. **Пайплайн записи:** Telegram Bot ➔ LLM Prompting (структурирование в Markdown) ➔ Запись `.md` в папку репозитория.
2. **Индексация:** Скрипт парсит Markdown-файлы, разбивает их на смысловые чанки, обогащает метаданными (теги, связи) и сохраняет эмбеддинги в ChromaDB.
3. **Пайплайн поиска:** Запрос пользователя ➔ Векторный поиск в ChromaDB (Retrieval) ➔ Передача контекста в LLM ➔ Генерация ответа со ссылками на источники.

## 🛠 Технологический стек

* **Language:** Python 3.11+ (Asyncio)
* **Telegram API:** `python-telegram-bot`
* **Vector Database:** `ChromaDB` (встроенный in-process движок)
* **LLM Orchestration:** Чистый Python SDK (`openai` / `ollama`) без тяжелых фреймворков для максимальной производительности.
* **Sync:** Git / GitHub Private Repo.
